# Manuel utilisateur – FloodWatch Citoyen

**Installer l'application** : ouvrez `https://<adresse>/` sur votre téléphone (ou scannez le QR code affiché
près des passages surveillés), puis faites « Ajouter à l'écran d'accueil ». Sur iPhone, l'installation est
nécessaire pour recevoir les notifications.

**Lire la carte** : chaque point surveillé est coloré selon son état.

| Couleur | Signification | Que faire ? |
|---|---|---|
| Vert : *Praticable* | niveau normal | circulez normalement |
| Jaune : *Surveillance* | pluie détectée, surveillance renforcée | restez attentif |
| Orange : *Prudence* | l'eau monte | évitez le passage si possible |
| Rouge : *Fermé* | barrière baissée | **ne vous engagez jamais**, prenez un autre itinéraire |
| Gris : *Indisponible* | station hors ligne | prudence, information non disponible |

La liste sous la carte indique le niveau d'eau, l'estimation du temps avant débordement et l'heure de la
dernière mise à jour. Touchez un point pour le centrer sur la carte.

**Recevoir les alertes** : touchez « Recevoir les alertes près de moi », choisissez le rayon (2 à 25 km) et
autorisez la localisation et les notifications. Vous serez prévenu dès qu'un passage proche passe en orange
ou en rouge, puis lorsqu'il rouvre. Le même bouton désactive les alertes.

**Hors connexion** : l'application affiche les dernières informations connues avec un bandeau
« Hors connexion ». Respectez toujours la signalisation sur place et les consignes de la protection civile (198).
